# Day A｜用 opencode 一步一步做出研究大表、跑 OLS

> 學生用。每一格「指令」整段複製貼到 opencode；它做完後，照「核對」那一行檢查，對了才貼下一步。
> 核對數字是老師 **2026-10-14** 從 TEJ 匯出的資料算的。
> **TEJ 會修正歷史資料**，你匯出的日期不同，第 5 步以後的數字可能差幾筆到幾十筆、係數差在小數第 3 位，這是正常的。差上百筆、或第 1–4 步就對不上，才是做錯了。
> 三個階段**各開一個新對話**（輸入 `/new`）；同一階段裡的步驟都在同一個對話裡做。

3. **把 opencode 整個關掉再重開**（skill 只在 opencode 啟動時讀一次）。
4. 問它「你有哪些 skill？」，要看到 `tej-data` 和 `run-ols`。

**核對**：資料夾這一層有 `AGENTS.md`、`.opencode`、`data`、`教材`，沒有多一層 `2026-NKUST-FMgnt` 資料夾。電腦沒有 git 的話：打開上面的網址，按綠色 **Code → Download ZIP**，解壓縮後整包放進你的資料夾（包括 `.opencode`）。

把 4 個 TEJ 檔放進 `data` 之後，再開始第 1 步。


## 階段二：下研究模型（第 11 步）

**先開一個新對話**（在 opencode 輸入 `/new`），再貼這一階段的指令。前一階段的檔案都在資料夾裡，新對話會自己去讀；老師測試時每個階段都是新對話。

模型是**你決定的**：指令裡「Y 是…；X 是…；控制變數是…；有…固定效果」那一段，就是你的研究模型。AI 只負責把它寫成 `model.json`，再複述給你看。

### 第 11 步

**指令**

```
先載入 run-ols skill。第 11 步：我的研究模型如下。Y（依變數）是 `Rate`；X（主要解釋變數）是 `TCRI`；控制變數是 `Size`、`MB`、`ROA`、`Debt`、`LLoan`、`LMaturity`、`CollateralD`；有產業和年度固定效果（`IND_` 和 `Year_` 開頭的欄位，各刪一欄當對照組）；有常數項；標準誤用一般 OLS（nonrobust）。讀 `panel.csv` 的欄位名稱和筆數，把這個模型照 run-ols skill 的格式寫成 `model.json`，欄名要跟 `panel.csv` 一模一樣，N 是 `panel.csv` 的筆數。然後用中文把模型複述一次給我看：Y、X、控制變數、固定效果和各用哪一欄當對照組、有沒有常數項、標準誤、樣本幾筆。不要跑迴歸。只做這一步。
```

**核對**：它複述的模型跟你寫的一樣：Y 是 `Rate`；X 是 `TCRI`；7 個控制變數一個不少；產業和年度固定效果都有，各刪一欄當對照組；**有常數項**；標準誤是一般 OLS；樣本 **19,344** 筆。再打開 `model.json` 看一次：`constant` 是 `true`、`se` 是 `"nonrobust"`

## 階段三：跑 OLS 並檢查（第 12–13 步）

**先開一個新對話**（在 opencode 輸入 `/new`），再貼這一階段的第一個指令。前一階段的檔案都在資料夾裡，新對話會自己去讀；老師測試時每個階段都是新對話。

### 第 12 步

**指令**

```
先載入 run-ols skill。第 12 步：讀 `panel.csv` 和 `model.json`，完全照 `model.json` 的設定跑 OLS。程式寫在 `step12.py`，結果存成 `results.csv`（UTF-8），欄位是 `variable,coef,t`，列出常數項（variable 寫 `const`）和 `model.json` 的每一個 x，最後兩列是 `N` 和 `adj_R2`（數字放在 coef 那一格）。虛擬變數的係數不用列。另外印出放進迴歸的變數數目：常數項幾個、X 和控制變數幾個、產業虛擬變數幾個、年度虛擬變數幾個、合計幾個。印出 results.csv 的內容。只做這一步。
```

**核對**：變數數目：常數 1 ＋ X 和控制變數 8 ＋ 產業 **32** ＋ 年度 11 ＝ **52**；有 `const` 那一列；N＝19,344；adj R² ≈ **0.32**（若接近 0.9，多半是常數項被拿掉）；係數對照下方「參考答案」

### 第 13 步

**指令**

```
第 13 步：寫 `step13.py`，讀 `panel.csv`、`model.json`、`results.csv`，用程式逐項檢查，結果寫成 `check.md`。`check.md` 是一張表，欄位是「檢查項目 | 應該是 | 實際是 | 通過？」，「通過？」填「是」或「否」，由程式判斷。至少檢查這 6 項：(1) results.csv 的 N 等於 panel.csv 裡 y 和每一個 x 都有值的筆數；(2) results.csv 列出的變數（const、N、adj_R2 以外）跟 model.json 的 x 一模一樣；(3) 有 const 那一列；(4) 產業、年度虛擬變數各放進「全部欄數減 1」欄，刪掉的正好是 model.json 的 ind_ref 和 year_ref；(5) 放進迴歸的變數合計數目，等於 1 ＋ x 的個數 ＋ 放進去的產業欄數 ＋ 放進去的年度欄數；(6) 照 model.json 重跑一次 OLS，每一個係數和 t 值都跟 results.csv 一樣（差在 0.0001 以內）。表的下面寫一句總結：全部通過，或列出沒通過的項目。印出 check.md 的內容。只做這一步。
```

**核對**：`check.md` 有 6 列以上，每一列都寫出「應該是」和「實際是」，「通過？」全部是「是」；總結寫「全部通過」。再抽一列自己對：例如 N 那一列，「應該是」跟你第 9 步的筆數一樣嗎？

## 發現錯誤時怎麼下修正指令

同一個 opencode 對話裡再打一句，寫清楚四件事：**錯在哪、應該是什麼（附理由）、要改哪幾個檔、改完印出來給我看**。例如：

```
我說要有常數項：產業和年度虛擬變數各刪一類當對照組，所以要放常數項。請把 model.json 改成有常數項，改完把 model.json 印出來給我看。
```

只說「不對」或只講症狀，它常常只改其中一個檔。
