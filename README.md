# 金融市場與機構管理｜Day A：信用比較差的公司，借款利率真的比較高嗎？

這個資料夾就是你上課用的**工作資料夾**。下載下來之後，在這個資料夾裡打開 opencode，照 `教材/學生指令與核對表.md` 一步一步做。

## 裡面有什麼

| 檔案 | 用途 |
|---|---|
| `AGENTS.md` | 給 opencode 看的工作規範（用繁體中文、做完要確認檔案、不可編造） |
| `.opencode/skills/tej-data/` | 資料整理 skill：TEJ 檔怎麼讀、變數怎麼算（第 1–10 步用） |
| `.opencode/skills/run-ols/` | 下模型、跑 OLS、檢查結果的 skill（第 11–13 步用） |
| `data/` | 放你從 TEJ 匯出的 4 個 `.txt` 檔 |
| `教材/課前-TEJ匯出步驟.md` | 怎麼從 TEJ+ 匯出那 4 個檔 |
| `教材/學生指令與核對表.md` | 上課要貼給 opencode 的 13 個指令，以及每一步的核對數字 |

## 怎麼下載

1. 開一個**新的、空的資料夾**當你的工作資料夾（放哪裡、叫什麼名字你自己決定）。
2. 在這個資料夾裡打開 opencode，貼這段：

   ```
   請用 git 把 https://github.com/guanyuhoujeff/2026-NKUST-FMgnt.git 下載到目前這個資料夾，檔案直接放在這一層，不要多一層子資料夾；資料夾裡原本的檔案不可以刪除或覆蓋。下載完列出這一層的檔案和 .opencode/skills 裡的資料夾。
   ```

3. **把 opencode 整個關掉再重開**（skill 只在 opencode 啟動時讀一次）。
4. 問它「你有哪些 skill？」，要看到 `tej-data` 和 `run-ols`。

電腦沒有 git 的話：在這個網頁按綠色的 **Code → Download ZIP**，解壓縮後把裡面的東西（包括 `.opencode` 這個隱藏資料夾）放進你的工作資料夾。

## 注意

- TEJ 匯出的資料**只能自己做研究用，不要上傳到任何公開的地方**（包括這個 repo 的 fork）。
- 核對表的數字是老師用 2026 年 10 月匯出的 TEJ 資料算的；TEJ 會修正歷史資料，你的數字差幾筆是正常的。
